# ⚔️ Three.js AI 战斗系统演示

*基于Three.js和Cannon.js的实时战斗游戏*

## 🎮 游戏特色

### 核心玩法
- **8种技能** - 火焰弹、冰冻术、雷击、治疗、暗影箭、必杀技、防御、普通攻击
- **5波敌人** - 史莱姆、哥布林、骷髅、火焰龙、恶魔领主
- **技能冷却** - 每种技能有独立冷却时间
- **经验升级** - 击败敌人获得经验，升级提升属性

### 技能系统
| 技能 | 效果 | MP消耗 | 冷却 | 备注 |
|------|------|--------|------|------|
| 🔥 火焰弹 | 25伤害 | 10 | 3s | 远程攻击 |
| ❄️ 冰冻术 | 15伤害 | 15 | 5s | 减速效果 |
| ⚡ 雷击 | 30伤害 | 20 | 8s | 高伤害 |
| ✨ 治疗术 | 30回复 | 15 | 10s | 恢复HP |
| 💀 暗影箭 | 40伤害 | 25 | 12s | 高爆发 |
| 🌟 必杀技 | 80伤害 | 40 | 30s | 终极技能 |
| 🛡️ 防御 | 双倍防御 | - | 15s | 持续3秒 |
| 💥 普通攻击 | 15伤害 | - | 1s | 近战 |

### 敌人类型
| 敌人 | HP | 攻击 | 速度 | EXP | 特点 |
|------|-----|------|------|-----|------|
| 👾 史莱姆 | 50 | 5 | 慢 | 20 | 基础敌人 |
| 👹 哥布林 | 80 | 10 | 中 | 35 | 平衡型 |
| 💀 骷髅 | 120 | 15 | 慢 | 50 | 高防 |
| 🐉 火焰龙 | 200 | 25 | 快 | 100 | Boss级 |
| 😈 恶魔领主 | 300 | 35 | 最快 | 200 | 最终Boss |

## 🚀 快速开始

### 1. 打开游戏

```bash
# 直接用浏览器打开
open combat-demo/index.html

# 或启动本地服务器
cd combat-demo
python3 -m http.server 8080
# 访问 http://localhost:8080/combat-demo/
```

### 2. 操作说明

| 操作 | 按键 |
|------|------|
| 移动 | W A S D |
| 技能1-4 | 1 2 3 4 |
| 技能5-8 | 5 6 7 8 |
| 鼠标点击 | 技能面板 |

## 🎯 游戏流程

```
第1波 → 第2波 → 第3波 → 第4波 → 第5波
  👾      👾👹     👾👹💀   👹💀🐉   😈最终Boss
```

### 波次奖励
- 每波敌人难度递增
- 击败Boss通关可获得胜利
- 经验可升级提升属性

## 📊 属性系统

### 玩家属性
| 属性 | 初始值 | 说明 |
|------|--------|------|
| 生命值 | 100 | HP归零则失败 |
| 法力值 | 50 | 施放技能消耗 |
| 攻击力 | 10 | 技能伤害加成 |
| 防御力 | 5 | 减免伤害 |

### 升级效果
- HP上限 +20
- MP上限 +10
- 攻击力 +5

## 💡 策略提示

1. **前期** - 优先使用低消耗技能
2. **中期** - 合理分配MP，注意冷却
3. **后期** - 保留必杀技对付Boss
4. **防御** - 关键时刻使用防御姿态

## 🔧 自定义

### 修改技能

编辑 `index.html` 中的 `CONFIG.skills`：

```javascript
skills: [
    { name: '新技能', damage: 50, mp: 30, cooldown: 15, color: '#ff0000' },
    // ...
]
```

### 添加敌人

```javascript
enemies: [
    { name: '新敌人', hp: 500, attack: 50, speed: 0.25, exp: 300 },
    // ...
]
```
