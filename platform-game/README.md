# 🎮 3D平台跳跃游戏

*Three.js + Cannon.js 物理引擎平台游戏*

## 🎯 游戏特色

### 核心玩法
- **3D平台跳跃** - 收集星星，挑战关卡，到达终点
- **物理引擎** - 真实的跳跃和碰撞
- **多关卡** - 3个递进难度的关卡
- **收集系统** - 每关10个星星，收集获得分数

### 游戏系统
| 系统 | 说明 |
|------|------|
| 🏃 移动控制 | WASD移动，空格跳跃，Shift加速 |
| ❤️ 生命值 | 3条命，掉落或敌人攻击扣血 |
| ⭐ 收集品 | 星星收集，每颗100分 |
| 👾 敌人 | 第2、3关出现，碰到扣血 |
| 🚪 终点 | 到达终点进入下一关 |

## 🚀 快速开始

```bash
# 直接在浏览器打开
open ThreeJSEvolution/platform-game/index.html
```

## 🎮 操作说明

| 按键 | 功能 |
|------|------|
| W/A/S/D | 移动 |
| 空格 | 跳跃 |
| Shift | 加速 |
| ESC | 暂停 |

## 📊 关卡设计

### 第一关：入门 🌟
- 6个平台
- 10个收集品
- 无敌人
- 难度：★☆☆☆☆

### 第二关：进阶 🌊
- 8个平台
- 10个收集品
- 2个敌人（巡逻）
- 难度：★★☆☆☆

### 第三关：挑战 🔥
- 9个平台
- 10个收集品
- 3个敌人（巡逻）
- 难度：★★★☆☆

## 🎯 游戏策略

1. **跳跃技巧** - 利用惯性跳更远
2. **收集顺序** - 先收集附近的星星
3. **敌人躲避** - 观察敌人移动规律
4. **安全第一** - 掉落会扣血
